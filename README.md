# 归序 · 桌面资料中心

一个黑色玻璃质感的 Windows 桌面浮窗，用来收集文件、整理资料、搜索文档、安排每日计划和控制音乐。

目前是源码版本，需要安装运行环境后启动。

## 功能

- **边缘浮窗**：默认收在屏幕上方，保留一个小箭头；支持靠近展开、双击标题栏收回、拖动和四边停靠。
- **收集与归档**：拖入文件或文件夹，选择本机可用空间最大的固定磁盘保存；文件夹保留原名称和内部目录，散件按类型存放。
- **搜索资料**：按文件名、路径、标签和可提取的正文查找，支持收藏和修改分类。
- **每日计划**：在同一个浮窗里管理待办事项。
- **音乐控制**：通过 Windows 媒体会话控制播放、切歌和受支持的进度操作，也可以调整系统音量。
- **桌面显示**：浏览器、游戏和其他应用处于前台时隐藏，回到桌面后恢复小箭头。

## 安装与启动

需要 Windows、Node.js 24 或更新版本，以及 pnpm。

先下载本仓库，或使用 Git 克隆：

```sh
git clone https://github.com/tifannie1/guixu.git
cd guixu
```

安装依赖和 Electron 运行环境：

```sh
pnpm install --frozen-lockfile
node node_modules/electron/install.js
```

然后双击项目中的「打开归序.cmd」，也可以运行：

```sh
pnpm desktop
```

## 使用方法

归序默认收在屏幕上边缘，只显示一个小箭头。鼠标靠近箭头稍停会展开，移开会收回。点击箭头可以直接打开。也可以从桌面或资源管理器把文件拖到屏幕上沿，等浮窗出现后松手。拖动浮窗顶部到屏幕任意一边可以停靠，下次启动会记住位置。

归序只在桌面显示。浏览器、游戏和其他应用处于前台时，面板、箭头以及边缘拖放区域都会隐藏。回到桌面后只恢复小箭头。资源管理器处于前台时仍可通过拖入文件唤起面板。

展开后可以搜索正文、改分类和标签、收藏、下载原件，以及管理每日计划。双击标题栏、点击外部或点击右上角的减号可收回屏幕边缘。托盘菜单可以调整停靠位置、隐藏箭头或退出。浮窗显示 Ctrl+Alt+G 时，可以用这个快捷键呼出浮窗。

展开浮窗后，可以从「音乐」进入媒体控制。Windows 有活动的媒体会话时，曲目也会自动显示在资料和计划页。切歌和播放进度等操作取决于播放器提供的功能；没有曲目时，仍可调整默认输出设备的系统音量。

桌面版每批归档会检查本机固定磁盘的可用空间，选择空间最大的盘，并在该盘的「归序资料库」保存原件。文件夹会保留原名称、子目录和空文件夹，散件会按类型存放。归档通过内容核对后，原位置的项目会移入回收站，供需要时恢复。资料库索引及计划仍存放在项目的 .local/data 目录。

桌面档案可以超过 30 MB。30 MB 及以内的常见 PDF、Office 文档和文本文件仍可提取正文，超出这个大小的档案按文件名、路径和类型查找。原有网页的上传入口仍采用复制和 30 MB 上限。

如果音乐正在播放但没有显示曲目，请检查播放器是否开启 **SMTC / Windows 系统媒体控制**。例如网易云音乐需要开启对应设置；播放控制能力取决于播放器提供的媒体会话。

## 项目结构

```text
desktop/     Electron 浮窗、归档和 Windows 系统集成
public/      界面、样式和文件分析
src/         服务接口与本地数据存储
drizzle/     数据库结构与迁移
scripts/     构建、启动与检查脚本
```

要使用网页布局，可以运行 `node scripts/launch.mjs`。单独构建可以运行 `pnpm build`，本地构建不需要云端托管配置。

## 数据存放

归档原件位于选中磁盘的「归序资料库」，索引和计划保存在 `.local/data/`。备份时需要同时保留这两部分；只下载源码不会恢复个人资料库。

`.gitignore` 已排除个人资料、运行数据、依赖、构建产物、调试截图和本地托管配置。GitHub 仓库用于保存项目源码。

## 第三方组件

PDF.js 随应用提供，并在 `public/vendor/` 中保留其许可证和相关字体许可证。
